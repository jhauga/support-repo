Install

Grid Rhythm is a CEP panel. There are two ways to install it: a development install from the source folder, and a signed ZXP package for end users.

Requirements

  • Adobe Illustrator 2026 (host ILST)
  • The source folder grid-rhythm/ from the project repository
  • Administrator access is not needed for the development install

Development install (unsigned)

Unsigned extensions only load when CEP's debug mode is on. You turn it on once per machine, then copy the extension folder into the CEP extensions directory.

1. Enable PlayerDebugMode on Windows

Set the PlayerDebugMode value for CSXS 12 to 1 in the registry. Run this in PowerShell as your user:

New-ItemProperty -Path "HKCU:\Software\Adobe\CSXS.12" -Name PlayerDebugMode -Value "1" -PropertyType String -Force

2. Enable PlayerDebugMode on macOS

defaults write com.adobe.CSXS.12 PlayerDebugMode 1

3. Copy the extension into the CEP folder

The extension folder name must match the bundle ID in CSXS/manifest.xml, which is com.example.gridrhythm.

PlatformTarget folder
Windows%APPDATA%\Adobe\CEP\extensions\com.example.gridrhythm
macOS~/Library/Application Support/Adobe/CEP/extensions/com.example.gridrhythm
 
# Windows (PowerShell)
Copy-Item -Recurse -Force ".\grid-rhythm\*" "$env:APPDATA\Adobe\CEP\extensions\com.example.gridrhythm"

# macOS (Terminal)
cp -R ./grid-rhythm/. "$HOME/Library/Application Support/Adobe/CEP/extensions/com.example.gridrhythm"

4. Restart Illustrator and open the panel

Quit and reopen Illustrator 2026, then choose Window > Extensions > Grid Rhythm.

Re-copy after each edit. Illustrator loads the files when the panel opens. After changing anything in js/, jsx/, or css/, copy the folder again and close and reopen the panel.

Debug port

The .debug file in the source folder opens Chrome DevTools on port 8088 for the Illustrator panel host. Use it to inspect the panel's JavaScript console and DOM. Open http://localhost:8088 in Chrome while Illustrator is running with the panel open.

Signed ZXP install (for release)

A ZXP is a signed, compressed CEP package. End users install it with a ZXP-capable installer tool, without enabling debug mode.

  1. Remove the .debug file from the package folder so the extension does not open a debug port.
  2. Create a signing certificate with ZXPSignCmd -selfSignedCert, or use a certificate from a trusted authority.
  3. Sign the folder with ZXPSignCmd -sign to produce grid-rhythm.zxp.
  4. Verify the package with ZXPSignCmd -verify before publishing.
ZXPSignCmd -selfSignedCert US Illinois "Acme Corp" "Jane Doe" grid-rhythm-cert.p12 "change-me-password"
ZXPSignCmd -sign ./grid-rhythm ./dist/grid-rhythm.zxp grid-rhythm-cert.p12 "change-me-password"
ZXPSignCmd -verify ./dist/grid-rhythm.zxp

Keep the certificate and its password out of the repository. Self-signed certificates are fine for internal testing; public distribution needs a certificate that you control and that Adobe's tooling accepts.

Remove the development install

Delete the com.example.gridrhythm folder from the CEP extensions directory above, then restart Illustrator.
