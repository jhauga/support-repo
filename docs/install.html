Acme Sting Install Usage Changelog

Install

Requirements

  • Adobe After Effects 2026 (version 26.x) on Windows.
  • PowerShell 5.1 or later, for run-sting.ps1.
  • ffmpeg on the PATH or at a known path, only if you want GIFs.

Development install (unsigned)

After Effects loads unsigned panels only when PlayerDebugMode is set for the CEP version. After Effects 2026 uses CEP 12, so the key is CSXS.12.

  1. Enable debug mode for the current user. Run this in Command Prompt and sign out or restart: 
    reg add "HKCU\Software\Adobe\CSXS.12" /v PlayerDebugMode /t REG_SZ /d 1 /f
  2. Link the panel folder into the CEP extensions folder. Use a junction so edits show up after a reload: 
    mklink /J "%APPDATA%\Adobe\CEP\extensions\acme-sting" "C:\path\to\acme-sting\panel"
  3. Restart After Effects, then open Window > Extensions > Acme Sting.

The .debug file in the panel folder names the host (AEFT) and a Chrome DevTools port (8088). To debug the panel, open http://localhost:8088 in Chrome.

Remove the development install

rmdir "%APPDATA%\Adobe\CEP\extensions\acme-sting"
reg delete "HKCU\Software\Adobe\CSXS.12" /v PlayerDebugMode /f

Running rmdir on the junction removes only the link. The panel files stay in the repository.

Install the script only

The panel and the command line both run jsx\acme-sting.jsx from the repository. Nothing else needs to be installed.

Signed ZXP (later)

For distribution, sign the panel into a .zxp with a timestamp, then install it with Adobe's Unified Plugin Installer Agent (UPIA). The panel has not been signed or packaged yet.

  1. Create a self-signed certificate with ZXPSignCmd -selfSignedCert.
  2. Sign the folder with ZXPSignCmd -sign, using a timestamp server.
  3. Install the ZXP with UPIA, or with a double-click.

ExManCmd no longer works with Creative Cloud 2022 and later apps.
