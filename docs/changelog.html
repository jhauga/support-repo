Changelog

Notable changes to Grid Rhythm, newest first.

0.1.0 - initial development build

  • Three-step CEP panel: size (1 to 20 rows, 1 to 10 columns), pattern mode (one row pattern or alternating rows), and design controls.
  • Shape sequence from square, circle, rectangle, ellipse, and a linked accent asset.
  • Fill step or mirror through a four-colour palette, with rotation steps of 0, 15, 30, 45, or 90 degrees.
  • Stroke weight that cycles by row, with dashes on every second row.
  • Live preview of the first four rows.
  • Host script draws on a new layer named Grid Rhythm, fitted to the active artboard with even gutters. A new document is created when none is open.
  • Linked asset placement uses a bundled .ai copy of the accent SVG. Illustrator's scripting API rejects SVG for PlacedItem.file.
  • Validation in the panel and in the host script. Invalid input returns a message and draws nothing.
  • Development install with PlayerDebugMode, and a documented ZXP packaging path.

Known limitations

  • Each Draw creates a new layer, so repeated draws leave several layers named Grid Rhythm.
  • The linked asset is an .ai copy, not the SVG, because of the scripting limit above.
  • Tested on Illustrator 2026 (30.1.0) only.
