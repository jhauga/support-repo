Show/Hide Toggle Button in Vanilla JavaScript

A button that toggles the visibility of the content next to it, and updates its own label to say "Show" or "Hide" depending on the current state, is a common UI pattern. Here's a small, dependency-free function that does exactly that for any button placed directly before the element it controls.

The function

const toggleShowHide = (button) => {
 const target = button.nextElementSibling;
 const isHidden = button.innerText.indexOf("Show") > -1;

 target.style.display = isHidden ? "" : "none";
 button.innerText = isHidden
  ? button.innerText.replace("Show", "Hide")
  : button.innerText.replace("Hide", "Show");
};

The function reads the button's own text to decide the current state, so no extra state variable or data attribute is needed. It relies on nextElementSibling, so the button and the element it controls must be adjacent in the markup.

Usage example

Wire the function up to a button's click event, and give the button a label that starts with "Show":

<button onclick="toggleShowHide(this)">Show details</button>
<p style="display:none">Hello, World!</p>

Live demo:

Clicking the button reveals the paragraph and relabels the button "Hide details"; clicking again hides the paragraph and restores the "Show details" label.

Limits

  • Only the single next sibling element is toggled - it won't reach further down the tree.
  • The button's label must contain the literal word "Show" or "Hide" for the text swap to work.
